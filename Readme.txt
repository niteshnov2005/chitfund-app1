========================================================================
CHIT FUND MANAGER - USER GUIDE
========================================================================

Welcome to the premium Chit Fund Manager desktop application! This offline 
software allows you to manage member details, track active monthly plan dues, 
run auctions, and view real-time AI payout suggestions securely.

------------------------------------------------------------------------
HOW TO START THE SOFTWARE
------------------------------------------------------------------------
1. Open the folder and double-click:
   ChitFundManager.exe

2. On the first launch, a welcome animation will display.

------------------------------------------------------------------------
INITIAL ONBOARDING SETUP
------------------------------------------------------------------------
1. Creating User Login:
   - When the login screen appears, click "Create Account" to set up your 
     own administrator username and password. 
   - These are saved locally inside your secure database backup.

2. Uploading the Spreadsheet:
   - On your first login, the dashboard will ask you to initialize your 
     ledger. 
   - Drag and drop the provided file:
     sample.xlsx
   - The wizard will detect the active plans. For each plan, select the 
     bid winner from the member list and enter the winning bid amount 
     (or leave blank/unassigned if the auction hasn't occurred yet).
   - Click "Save & Complete Setup" to open the dashboard!

------------------------------------------------------------------------
FEATURES & NAVIGATION
------------------------------------------------------------------------
- Dashboard: Real-time overview showing total collections, paid and 
  pending members, and AI Payout Recommendations advising how much 
  to pay bid winners.
- Members: Add new members, remove old accounts, edit names or areas.
- Run Auction: A 3-step setup wizard that guides you through checking 
  active plans, updating member records, and entering bids to generate 
  the next month's ledger sheet automatically.

------------------------------------------------------------------------
DATA BACKUP
------------------------------------------------------------------------
- All your transactions and actions are mirrored into a local relational 
  database file "backup.db" in real-time.
- You can trigger manual backups from the SQL Backup card on the dashboard.
