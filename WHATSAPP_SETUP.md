# WhatsApp Receipts (no API, no Meta account)

On **View Receipts**, each member card has:
- **WhatsApp**: opens a chat with that member (number saved for next time) with the receipt text pre-filled. Tap Send in WhatsApp.
- **Share Image**: on a phone, opens the share sheet with the receipt PNG so you can pick WhatsApp and the member's chat. On desktop it downloads the image to attach manually.

Enter numbers with country code (e.g. 919876543210). 10-digit numbers are assumed to be India (+91).
